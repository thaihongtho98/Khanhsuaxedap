# 🚲 Tiệm Sửa Xe Ông Khanh - Website Giới Thiệu & Liên Hệ

Trang web giới thiệu dịch vụ sửa chữa tất cả các loại xe đạp của **Tiệm Sửa Xe Ông Khanh**, được thiết kế theo phong cách hiện đại, tối ưu hiển thị trên mọi thiết bị (Responsive) và tích hợp sẵn các liên kết mạng xã hội, bản đồ.

---

## 🛠️ Công Nghệ Sử Dụng
* **HTML5 / CSS3**: Xây dựng bố cục và giao diện hiện đại, sạch sẽ.
* **Font Awesome**: Cung cấp các biểu tượng (icons) trực quan, sinh động.
* **Google Maps Embed**: Nhúng bản đồ giúp khách hàng dễ dàng tìm đường tới tiệm.

## 🚀 Hướng Dẫn Sử Dụng & Triển Khai (Deploy)

### 1. Chạy thử trên máy tính (Local)
1. Tải toàn bộ mã nguồn website và lưu thành file có tên `index.html`.
2. Nhấp đúp chuột vào file `index.html` để mở trực tiếp trên trình duyệt web bất kỳ (Chrome, Firefox, Edge, Safari...).

### 2. Đưa website lên Internet miễn phí
Bạn có thể đưa trang web này lên mạng để khách hàng dễ dàng tra cứu qua điện thoại bằng một trong các cách sau:
* **GitHub Pages:** Tải file `index.html` lên một repository trên GitHub và kích hoạt tính năng GitHub Pages.
* **Netlify / Vercel:** Kéo thả file `index.html` trực tiếp lên trang chủ của Netlify hoặc Vercel để nhận ngay một đường link (URL) truy cập công khai miễn phí.
